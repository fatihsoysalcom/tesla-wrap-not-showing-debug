# Tesla Wrap Not Showing Debug

This example demonstrates common reasons why a digital wrap or texture might not appear on a 3D model, using a simple HTML div as a "Tesla model." It simulates issues like incorrect image paths and visibility problems, providing interactive buttons to apply and troubleshoot the "wrap."

## Language

`html`

## How to Run

Open `index.html` in your web browser. Click the buttons to see how different issues affect the digital wrap's visibility.
